## 🚀 Quick Start

### Prerequisites
- Docker

### Installation

```bash
# Clone the repository
git clone https://github.com/Samuelade24/solagates.git
cd solagates

# Build and run
docker build -t solagates .
docker run -d --name solagates -p 8085:80 solagates

# Access the application
open http://localhost:8085
```
